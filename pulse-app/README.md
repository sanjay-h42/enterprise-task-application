# PULSE App — Frontend Client (React 19 + Vite + Tailwind CSS)

This directory contains the single-page application (SPA) frontend for the **PULSE Performance Management System**.

👉 **For complete project documentation, system architecture, feature breakdown, and backend setup, see the root [README.md](../README.md).**

## 🚀 Quick Start (Frontend)

```bash
# Install dependencies
npm install

# Start local Vite development server
npm run dev
```

The application will be available at `http://localhost:5173`.

## 📦 Scripts

- `npm run dev` - Start local development server with Hot Module Replacement (HMR)
- `npm run build` - Build production bundle to `dist/`
- `npm run lint` - Run Oxlint code checker
- `npm run preview` - Preview production build locally
